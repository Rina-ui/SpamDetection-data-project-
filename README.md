Dataset: SMS Spam Collection (Kaggle)
Guide: SMS Spam Classifier — Naive Bayes (Kaggle notebook)
Description: Build a classifier that labels a text message as spam or ham. You'll clean the text, turn it into numbers with TF-IDF or a count vectorizer, and train a Naive Bayes model. This is the perfect intro to NLP and text classification: 5,500+ labeled messages, a tiny dataset that trains in seconds, and a result you can actually test by typing in your own message. Skills: text preprocessing, TF-IDF, Naive Bayes, train/test split, precision and recall.
